## Provenance（可追溯链）

- Info API：`https://evermeet.cx/ffmpeg/info/{ffmpeg,ffprobe}` → 各返回
  `version` + 版本化直链 + `size` + `.sig`。脚本核对 **size 逐字节一致**
  （ffmpeg.zip 26501987 / ffprobe.zip 26397092）并保存上游 `.sig` 签名文件。
- 两个二进制**同一上游构建号**（脚本强制校验，ffmpeg/ffprobe 版本不一致即失败）。
- 上游旧端点状态实测记录：`getrelease/zip` 与 `get/<tool>/zip` 均 **410**
  （已废弃）；Info API **200** 可用——脚本仅依赖 Info API。
- 构建器：Apple clang 17.0.0 (clang-1700.6.4.2)。

## License — GPL-3+（事实记录，非 LGPL）

`ffmpeg -version` configuration 含 **`--enable-gpl --enable-version3` +
`--enable-libx264 --enable-libx265`**（脚本自动检查并记录；`--enable-nonfree`
不存在，若出现脚本直接拒绝打包）。

- 分发未修改的 GPL 二进制合法（需随附源码获取信息：evermeet.cx 按构建号
  发布源码链接）。
- Fluixa 通过**独立进程**调用，GPL 不传导至 Fluixa 应用本体；但
  **未经法务审核不得标记为可直接商用分发**。
- LGPL 构建方案（研究结论，未实施）：自建 `--disable-gpl --disable-libx264
  --disable-libx265 --enable-libopenh264`（OpenH264 是 BSD 许可、Cisco 预编译
  二进制另有分发条款）或纯系统编码器；代价是失去 libx264 的编码质量/速度
  生态，且需要建立 macOS 双架构自建 CI。列入后续工作。
